# База данных ИС «Интернет-магазин»

SQL-скрипты базы данных магазина. Схема повторяет модель приложения
(`ShopDbContext`, EF Core) и ER-диаграмму: 16 таблиц с теми же именами
таблиц и столбцов.

| Файл | СУБД | Для чего |
|---|---|---|
| `shop.sqlite.sql` | SQLite 3 | Та же база, что создаёт приложение (`shop.db3`): типы, ключи, индексы и формат дат как у EF Core |
| `shop.postgresql.sql` | PostgreSQL 13+ | Та же схема на «серверных» типах: UUID, TIMESTAMPTZ, NUMERIC, BOOLEAN, VARCHAR(n) |

Каждый скрипт состоит из трёх частей:

1. **Создание таблиц**: первичные и внешние ключи (с правилами `ON DELETE`),
   уникальные индексы, `CHECK`-ограничения (оценка 1–5, количество 1–99,
   коды перечислений, email или телефон у пользователя и т. д.).
2. **Тестовые данные**: 5 и больше записей в каждой таблице. Товары и
   категории взяты из `DemoCatalog.cs`; заказы есть во всех статусах
   (оформление, ожидает оплаты, подтверждён, курьер назначен, в доставке,
   завершён, отменён), с отклонённым и возвращённым платежом и
   несостоявшейся доставкой. Есть пользователь, зарегистрированный только
   по телефону, заблокированный и удалённый (обезличенный) аккаунты.
3. **Пять проверочных запросов** (`WHERE`, `ORDER BY`, `JOIN`, `GROUP BY`,
   `HAVING`, `LEFT JOIN`).

## Запуск

SQLite (или DB Browser for SQLite → «Выполнить SQL»):

```sh
sqlite3 shop.db3 < Database/shop.sqlite.sql
```

PostgreSQL (или pgAdmin → Query Tool):

```sh
createdb shop
psql -d shop -f Database/shop.postgresql.sql
```

Скрипты можно запускать повторно: таблицы удаляются и создаются заново.

## Демо-пользователи

| Логин | Пароль | Роль |
|---|---|---|
| buyer | Buyer123! | Покупатель |
| anna | Anna123! | Покупатель (только телефон +79161234567) |
| petr | Petr123! | Покупатель, заблокирован |
| manager | Manager123! | Менеджер по продажам |
| owner | Owner123! | Владелец |
| logist | Logist123! | Логист |
| courier, courier2 | Courier123! | Курьер |

Пароли хранятся хэшем PBKDF2-SHA256 в формате `Pbkdf2PasswordHasher`.

## Связь с приложением

Приложение создаёт базу само (`EnsureCreated` + сид в `DatabaseInitializer`),
скрипт ему не нужен. Файл, созданный `shop.sqlite.sql`, совместим с моделью
EF Core: даты записаны тем же числом, что пишет `DateTimeOffsetToBinaryConverter`,
Guid — строкой в верхнем регистре. При изменении модели обновите скрипты и
ER-диаграмму вместе с кодом.
